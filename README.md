# CV WEBSITE

## User profile:
The target user for this project is someone who works as an HR Manager or recruiter in a technology or medical-device company. This person is responsible for finding candidates with technical skills and relevant work experience.

Since this person has to review many CVs every day, the main goals of this project are:
- A clear and well-organized CV.
- Easy access to contact information.
- The ability to quickly understand the candidate's academic background and work experience.
- A simple and intuitive navigation experience, with direct links to relevant websites and projects.
- A visual design that is professional but also personal.

## Information architecture:
The website is structured as a personal CV divided into three main areas: a sidebar, a main information section and a footer.

The sidebar is located on the left side of the page and contains complementary information about me. It includes four sections: Contact, Skills, Languages and Additional. The Contact section provides my main contact details, including a phone number, email address and location. The Skills section presents my technical and personal skills. The Languages section shows the languages I speak and my corresponding levels. Finally, the Additional section includes two complementary courses I have completed.

The main information section is located on the right side of the page and contains the most relevant information about my academic and professional background. It includes three sections: Personal information, Education and Work experience. The Personal information section includes a short personal description and a photograph. The Education section presents my academic background in chronological order, including completed and ongoing studies. Finally, the Work experience section describes my previous and current jobs and the main responsibilities I had in each position.

The footer is located at the bottom of the page and contains the Portfolio section. This area presents two selected academic projects, including a short description of each one and links to access further information when available.

This structure separates personal details from academic and professional information, making the content easier to find. It also gives the portfolio a dedicated space.

## Visual design:
The main goal of the visual design is to create a simple, clear and organised website that presents personal, academic and professional information in an accessible way. I have chosen a soft colour palette based on pink and peach tones to give the website a friendly and approachable appearance while maintaining a clean and professional look.

The main background is a peach colour (#FF9886), while the three main sections are a light pink (#FEEBE7). Inside these main sections, each individual content box uses a stronger pink colour (#FFBAAD). This contrast helps distinguish the different areas of the website without using too many colours. Black is used for the text and borders to ensure readability and create a clear separation between the content blocks.

I use separate content boxes with borders, rounded corners and internal spacing to organize the information. The headings are also underlined and links are included to provide access to external websites and additional project information.

The layout is based on a two-column structure with a footer. The sidebar is placed on the left and has a fixed width, while the main information section occupies the remaining horizontal space. The footer extends across the bottom of the page.
